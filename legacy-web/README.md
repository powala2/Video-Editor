# Legacy web prototype (superseded)

This folder holds the original **web/Electron** version of Video Studio — the
high-fidelity design prototype imported from Claude Design and wrapped in
Electron. It looked like a full editor but most of its controls (split, trim,
delete, timeline, captions, zoom) were **decorative**; only import, screen
record, playback, and save actually did anything.

It has been replaced by the real desktop application at the repository root
(Python + PySide6), where those features actually work. This copy is kept only
for reference. To run it, see the git history or open `index.html` over a local
web server; it is no longer maintained.
